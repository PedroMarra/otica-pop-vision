# Ótica Pop Vision

Landing page da Ótica Pop Vision. Site estático (HTML + CSS + JS), publicado pelo GitHub Pages.

## Como editar

- **Número do WhatsApp:** abra `script.js` e preencha `const WHATSAPP = '55DDDNUMERO';`. Todos os botões passam a usar esse número.
- **Textos:** estão todos em `index.html`.
- **Cores:** variáveis no topo de `styles.css` (`--amarelo`, `--preto`, `--dourado`).
- **Foto da fachada:** substitua `assets/fachada.jpg` por uma foto em boa resolução.
- **Logo:** desenhado em SVG dentro do `index.html` (bloco `<symbol id="logo">`). Pode ser trocado pelo arquivo original.
